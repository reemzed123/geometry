# סטודיו גיאומטריה

יישום שולחני ל-Windows המבוסס על קובץ ה-HTML המקורי, עטוף ב-Electron.

## בניית EXE
לאחר העלאת הקבצים למאגר GitHub, GitHub Actions יבנה את קובצי Windows.
1. פותחים את לשונית **Actions** במאגר.
2. בוחרים את הריצה האחרונה של **Build Windows EXE**.
3. מורידים את **Geometry-Studio-Windows** מאזור Artifacts.

הבנייה מפיקה גרסה ניידת (Portable) וקובץ התקנה (NSIS).
